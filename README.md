# 🎮 Gerencie Lista Games

Uma aplicação full-stack desenvolvida para organizar e gerenciar uma biblioteca pessoal de jogos, permitindo o cadastro, visualização e exclusão de títulos.

## 🔗 Link do Projeto
🚀 [Acesse o site ativo aqui](https://listagames.infinityfreeapp.com)
*(Nota: O back-end é servido via túnel seguro durante períodos de desenvolvimento/teste).*

### **Front-end**
* **HTML5 & CSS**: Estruturação e estilização personalizada.
* **JavaScript (ES6+)**: Consumo de API REST e manipulação dinâmica do DOM.

### **Back-end**
* **Java com Spring Boot**: Criação da API RESTful com arquitetura MVC.
* **Spring Data JPA**: Abstração da camada de persistência.
* **PostgreSQL**: Banco de dados relacional para armazenamento dos jogos.

### **Ferramentas de DevOps/Deploy**
* **InfinityFree**: Hospedagem do front-end.
* **ngrok**: Exposição segura do servidor local para a web.

---

## 🚀 Funcionalidades
- [x] Cadastro de novos jogos com validação de campos.
- [x] Listagem em tempo real consumindo API externa.
- [x] Sistema de exclusão de registros.
- [x] Suporte a capas de jogos via URL.
- [x] Filtro visual para jogos ativos/inativos.
